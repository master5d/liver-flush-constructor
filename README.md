# Конструктор печёночного детокса

Статическая страница: собирает маршрут очищения печени под ваши условия (время, кухня, доступ к добавкам, противопоказания), показывает пошаговый план и шпаргалки с доказательным статусом каждого шага.

**Это не медицинская рекомендация и not a medical diagnosis.** Перед любой практикой из уровней A5–A7 — врач.
